# System-tool triggers (ADR-052 Amendment 1, section 2, "Classification",
# rule 2). Read by Suno_installer/classify.py.
#
# A package is a system tool when a polkit .policy names an
# org.freedesktop.policykit.exec.path, when a file is setuid, setgid or
# carries file capabilities, or when its launcher's Exec runs pkexec. A system
# tool is a system module labelled "full control of this computer". Only
# privilege on the package's main binary (named like the package) or a
# launcher that runs only through pkexec counts; see [hints].
#
# [exec]      fnmatch patterns for a launcher's program (the first word of
#             Exec, base name) that mean "runs itself through pkexec":
#             pkexec itself and the distributions' pkexec wrappers
# [dropped]   setuid or capability files that are dropped in an application
#             tree without loss: the application keeps working, so they do not
#             make it a system tool (Chromium's setuid sandbox: bubblewrap
#             keeps nested user namespaces, which Chromium uses instead)
# [optional]  privileged helpers (exec.path or setuid) of an application that
#             are named as not working instead of making it a system tool;
#             the application's main purpose does not need them
# [hints]     "pattern text": the line shown when a command that is not the
#             package's main binary loses its setuid bit or capabilities in
#             the workspace (rule 2 narrowed: only a main binary that needs root
#             makes a system tool)
#
# [admin-libraries]  libraries that reach devices, the kernel or the network
#             (partitions, device mapper, netlink, netfilter, PCI, USB, udev,
#             modems, tracing). A command-line package whose commands are all in
#             sbin and that links one of these is a command-line system tool:
#             it needs real root, which a workspace's sudo (mapped root) is not.
#             Commands only in sbin without one of these, and commands
#             elsewhere that link one (lsusb, aptitude), are a choice. Package
#             managers' libraries are here: a tool that changes packages acts on
#             the system.
#
# One fnmatch pattern per line; [dropped], [optional] and [hints] match
# absolute paths, [admin-libraries] package names.
