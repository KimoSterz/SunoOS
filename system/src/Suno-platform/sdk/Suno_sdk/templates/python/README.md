# @APP_NAME@

Generated by the Suno SDK. This is one adaptive GTK/libadwaita application,
not separate desktop and phone implementations.

Run the static contract checks with:

```sh
Suno lint Suno-app.toml
Suno inspect Suno-app.toml
Suno test Suno-app.toml
```

`Suno lint` verifies the shared application identity, Flatpak permission
policy, AppStream/desktop metadata, responsive declaration, and lifecycle
contract. A new project intentionally reports `Development`, not `Native`.
After CI has filled `verification/Suno-native-evidence.json`, generated an
SBOM and test report, and pinned every network source by immutable digest, run
`Suno release-check Suno-app.toml`. Only that evidence-derived check can report
a Native candidate; repository review/signing awards the public Native tier.

Run the application with `./run-app` after installing the Suno Developer
Platform libraries and typelibs.
