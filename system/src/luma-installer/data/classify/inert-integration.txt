# Inert integration of command-line tools (ADR-052 Amendment 1, section 2,
# "Classification", rule 1). Read by luma_installer/classify.py.
#
# Rule 1 makes any system unit, cron job or boot-image hook a system module.
# Base tools carry such files only to look after themselves (a nightly
# database backup, the man index, fstrim, apt's daily refresh) or to copy
# themselves into the initramfs. In a workspace or an application's tree they
# stay inert, like every other unit there, and they do not make the request a
# system module; the reasons name them. A real service (a daemon the person
# installs the package for) never belongs here.
#
# One fnmatch pattern per line, against absolute paths ("*" also matches "/").
