Summary: One install sheet for every app
Details: Installing an app shows what it can reach: only files you pick, the folders it needs, or all your files, with the suggested choice marked, what it uses, and its device access. Depot asks with the same sheet. Apps installed from the command line install right away and offer the same sheet afterwards.
