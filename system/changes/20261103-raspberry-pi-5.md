Summary: Raspberry Pi 5 image
Details: Raspberry Pi 5 builds use the Suno Pi kernel, which adds Bluetooth, HDMI audio on both ports, hardware HEVC video decoding, fan control, the real-time clock and the firmware's device tree with config.txt overlays. They update from the same ARM channel as every other ARM computer.
